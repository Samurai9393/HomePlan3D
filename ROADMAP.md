# Roadmap

*Deutsch weiter unten.*

There is no public roadmap any more. Plans published here were rebuilt elsewhere within days, so new features are announced when they are released.

- **What is new:** the [changelog](CHANGELOG.md) and the release archive in `docs/`.
- **Ideas and wishes:** use the issue tracker and discussions in this repository.
- **Bugs:** use the issue tracker in this repository.

The principle stays: HomePlan 3D is fully MIT open source. Every feature is free and enabled by default through `custom_components/homeplan3d/open-source-config.json`, including all Pro features, Pool Pro and the room bar. No account, licence key, shop or cloud is needed; safety features remain included.

# Roadmap (Deutsch)

Es gibt keine öffentliche Roadmap mehr. Pläne, die hier standen, wurden innerhalb weniger Tage anderswo nachgebaut. Neue Funktionen werden deshalb erst angekündigt, wenn sie erscheinen.

- **Was neu ist:** das [Changelog](CHANGELOG.md) und das Release-Archiv unter `docs/`.
- **Ideen und Wünsche:** Issue-Tracker und Diskussionen in diesem Repository.
- **Fehler:** Issue-Tracker in diesem Repository.

Der Grundsatz bleibt: HomePlan 3D ist vollständig MIT-open-source. Jede Funktion ist kostenlos und über `custom_components/homeplan3d/open-source-config.json` standardmäßig aktiviert – einschließlich aller Pro-Funktionen, Pool Pro und der Raumleiste. Kein Konto, kein Lizenzschlüssel, kein Shop und keine Cloud nötig; Sicherheitsfunktionen sind immer dabei.
