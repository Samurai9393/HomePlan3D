# Roadmap

*Second version below.*

There is no public roadmap any more. Plans published here were rebuilt elsewhere within days, so new features are announced when they are released.

- **What is new:** the [changelog](CHANGELOG.md) and the release archive in `docs/`.
- **Ideas and wishes:** use the issue tracker and discussions in this repository.
- **Bugs:** use the issue tracker in this repository.

The principle stays: HomePlan 3D is fully MIT open source. Every feature is free and enabled by default through `custom_components/homeplan3d/open-source-config.json`, including all Pro features, Pool Pro and the room bar. Everything runs locally; safety features remain included.
