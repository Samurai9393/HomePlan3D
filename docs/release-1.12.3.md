**Nine new languages** – HomePlan 3D now speaks 16 languages.

### New

- **Danish, Swedish, Norwegian (Bokmål and Nynorsk), Finnish, Czech, Polish, Romanian and Slovenian.** HomePlan 3D follows the language of your Home Assistant user (profile → language); a language file is only fetched when it is needed, so the bundles stay small for old, weak wall tablets. Thanks to **zanzei26** for the Norwegian translation it builds on (#233).
- The setup dialog of the integration is now translated into every language as well.

Native speakers welcome: if a text sounds odd in your language, please open an issue or a discussion – a quick note with the better wording is enough.

### Fixed

- French, Spanish, Dutch, Italian and Hungarian: the restart notice shows both versions again.

### How to update

Settings → System → Updates. If HomePlan 3D is missing there: HACS → HomePlan 3D → ⋮ → **Update information** → **Download**. Then restart Home Assistant and reload the page (Ctrl+F5).
