# Furniture pack palette roles

## 2026-11-23 — Color roles are defined in the 3D viewer palette
- What: `fp3dpack` part `color`/`top` accept `#rrggbb` or a role name. Allowed roles are validated in `custom_components/homeplan3d/packs.py:37-40`. The 3D values live in `frontend/src/viewer/furniture.ts:18-38` (`BASE`, built with `palette(neon, natural)`): `body`/`bodyTop`, `fabric`/`fabricTop`, `cushion`, `wood`/`woodTop`, `white`/`whiteTop`, `front`/`frontTop`, `metal`, `dark`, `glass`, `plant`/`plantTop`, `pot`, `accent`. `packColor()` at `frontend/src/viewer/furniture.ts:1963-1967` parses hex directly and otherwise looks up the role, then the `${role}Top` variant; `palette()` at `frontend/src/viewer/palette.ts:35-37` switches neon/natural tables; a placed item's finish can override roles through the proxy at `frontend/src/viewer/furniture.ts:44-45`. 2D symbols use SVG/CSS classes in `frontend/src/components/furniture2d.ts`, not these roles.
- Why: User-facing pack examples use roles such as `plant` and `pot`. Future templates and example items must use valid role names or hex colors, and role colors intentionally change with the look and finish instead of being fixed.
