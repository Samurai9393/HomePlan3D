# General

- 2026-11-22 — When the user says `Create a Prompt for: <request>`, create a prompt for that request and write it to a `.md` file in the `Prompts/` folder for later review and execution. Do not execute the request.
- 2026-11-22 — When the user says `Create a Plan for: <request>`, create a plan for that prompt/request and write it to a `.md` file in the `Plans/` folder for later review and execution. Do not execute the plan.
- 2026-11-22 — For any code-changing prompt, create a descriptively named branch from `main` before editing; the user alone merges to `main` (keeps main user-controlled).
